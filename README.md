# Clase Práctica 2: Lista Simplemente Enlazada

Tres operaciones sobre la lista enlazada: eliminar
repetidos, rotar a la derecha y concatenar dos listas.

## Archivos

- `IList.java`, `Node.java`
- `LinkedList.java` - con los tres métodos nuevos: `removeDuplicates()`,
  `rotateRight()` y `concat(LinkedList<E> otra)`
- `Main.java` - casos de prueba

## Ejecutar

```bash
javac *.java
java Main
```
